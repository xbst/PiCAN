# PiCAN
[YouTube Video](https://youtu.be/SH-faxCCbi8)
![PCB](./Images/PCB.jpg)

A compact, USB drive shaped USB to CAN adapter, primarily intended for 3D printers running Klipper firmware.

## Purchasing a PiCAN
- [Isik's Tech Official Store](https://store.isiks.tech/products/pican-usb-to-can-bus-adapter)
- [Resellers](https://docs.isiks.tech/pican/manual/#resellers)

## Documentation
For firmware flashing, wiring, and Klipper CAN setup, see the [PiCAN manual](https://docs.isiks.tech/pican/manual/).
